Test Data Management (TDM) Lifecycle

Dynamic containerization and transaction-level isolation

1
Dynamic Ephemeral Container (Testcontainers)

Test session pulls and executes PostgreSQL 16 on a dynamically assigned host port, preventing port collisions across parallel test runs.

2
DDL Schema Migration

SQLAlchemy metadata creates all tables (products, orders, order_items) afresh in the isolated database.

3
Transaction Rollback Isolation

Each test case executes within a nested SQLAlchemy transaction. Upon test exit, transaction.rollback() restores the clean database state in under 5 milliseconds.

4
Zero-State Teardown

When the pytest session terminates, Testcontainers automatically tears down and cleans up the Docker container, leaving zero lingering state.
